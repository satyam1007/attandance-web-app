How to Use This Attendance System / इस सिस्टम का उपयोग कैसे करें

📌 Step 1 — Create or Load Class / कक्षा बनाएं या लोड करें

Enter your Class Name and Section, then click "Load/Create Class". यह जानकारी भरें और "Load/Create Class" दबाएं।

📌 Step 2 — Add Students / छात्र जोड़ें

Go to "Students" tab → Click "Add Student" → Enter name, roll number & optional photo. "Students" टैब में जाएं, "Add Student" दबाएं और विवरण भरें।

📌 Step 3 — Mark Attendance / उपस्थिति दर्ज करें

Open "Mark Attendance" tab → Select date → Mark Present/Absent → Save. "Mark Attendance" टैब खोलें, तारीख चुनें और उपस्थिति सेव करें।

👉 If Present/Absent/Leave is not showing, click "Update Attendance" button or refresh the page. अगर Present/Absent/Leave नहीं दिख रहा है तो "Update Attendance" दबाएं या पेज reload/refresh करें।

📌 Step 4 — View Attendance History / उपस्थिति इतिहास देखें

Go to "Attendance History" to view daily records. दैनिक रिकॉर्ड देखने के लिए "Attendance History" में जाएं।

📌 Step 5 — Generate Report / रिपोर्ट बनाएं

Select a student & month → Click "Generate Report". छात्र और महीना चुनें → "Generate Report" दबाएं।

📌 Step 6 — Fees, Marks & Leave Management / फीस, मार्क्स और अवकाश प्रबंधन

Use respective tabs to save fee status, exam marks & leave requests. संबंधित टैब में फीस, मार्क्स और अवकाश दर्ज करें।

📌 Step 7 — Export Data / डेटा डाउनलोड करें

Export Students, Attendance & Reports using Export section. Export सेक्शन से CSV और PDF डाउनलोड करें।

✅ Auto Save Feature / स्वतः सेव सुविधा

All data is auto-saved in browser — no internet required. सारा डेटा ब्राउज़र में स्वतः सेव रहता है — इंटरनेट जरूरी नहीं।

⚠️ Warning / चेतावनी

Do NOT clear browser storage, otherwise data will be erased. ब्राउज़र स्टोरेज क्लियर न करें, वरना डेटा हट जाएगा।

🎯 Best Use / बेहतर उपयोग

Use in Chrome or Laptop for best experience. बेहतर अनुभव के लिए Chrome या Laptop का उपयोग करें।
